# Apex Fit

حاسبة سعرات ونسبة دهون وخطة تمارين بالعربي، من شركة **Apex**.

Free Arabic fitness calculator: estimate body fat percentage, daily calories, macros and a weekly workout plan from your height, weight, age and sex.

**الموقع / Live site:** https://YOUR-USERNAME.github.io/apex-fit/

## المميزات

### النسخة المجانية
- نسبة الدهون التقريبية وكمية الدهون والكتلة بدون دهون
- مؤشر كتلة الجسم والوزن المثالي
- السعرات اليومية (BMR وTDEE) حسب مستوى النشاط والهدف
- توزيع البروتين والكربوهيدرات والدهون
- جدول تمارين أسبوعي عام

### النسخة المدفوعة (PRO)
- خطة أكل يومية بوجبات وسعرات وماكروز لكل وجبة
- جداول تمارين تفصيلية بالتمرين والعدد والتكرار
- تتبع التقدم بالوزن ومحيط الوسط مع رسم بياني

## Features

- Body fat estimate (Deurenberg formula), BMI, fat and lean mass
- BMR (Mifflin-St Jeor) and daily calorie target for fat loss, maintenance or muscle gain
- Macro split and weekly workout plan
- PRO: detailed meal plan, exercise sets and reps, progress tracker

## تنبيه

الأرقام تقديرية ومحسوبة بمعادلات عامة، وممكن تختلف عن القياس الحقيقي. البرنامج مش بديل لاستشارة دكتور أو أخصائي تغذية، خصوصًا لو عندك مرض مزمن أو حمل أو بتاخد أدوية.

*Estimates only. Not medical advice.*
